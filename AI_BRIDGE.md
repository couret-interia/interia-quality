# 🤝 InterIA AI Bridge (v4)

<details><summary><b>🇫🇷 Français</b> — cliquer pour déployer</summary>

## 🤍 Manifeste AI-Bridge InterIA

Nous ne demandons pas à l’IA de décider à notre place.
Nous lui demandons d’ouvrir des chemins.

Le pont IA d’InterIA n’est pas une boîte noire :
c’est un dialogue structuré, transparent, JSON contre JSON,
où chaque suggestion peut être lue, comprise, discutée, refusée.

L’IA n’est pas un oracle.
C’est un collègue de travail
avec qui nous partageons le plan (refactor_plan.json)
et à qui nous demandons :
« Comment rendre cela plus clair, plus lisible, plus harmonieux ? »

Le dernier mot reste humain.
Toujours.

---

Le module `interia_quality.refactor.ai_bridge` fournit un contrat JSON
entre le **Quality Pack v4** et n’importe quel LLM ou outil d’IA externe.

---

## 1. Fichiers impliqués

- `refactor_plan.json`
  → généré par `make` ou `make refactor-plan`
  → contient les suggestions de refactor (Python + Markdown + LaTeX)

- `ai_request.json`
  → généré par `make ai-request`
  → structure propre, IA-agnostique, prête à être envoyée à un LLM

- `ai_response.json`
  → fourni par l’IA externe
  → doit respecter le format attendu (`project`, `edits`, etc.)

---

## 2. Commandes utiles

```bash
# Construire le plan de refactor
make refactor-plan

# Construire la requête IA (json seul)
make ai-request

# Construit la requête et un prompt IA
make ai-prompt

# Résumer la réponse IA
make ai-summary

# Prévisualiser les modifications
make ai-preview

# Appliquer les modifications
make ai-apply
```

---

## 3. Format attendu de `ai_response.json`

```json
{
  "project": "interia_quality_pack_v4",
  "edits": [
    {
      "file": "path/to/file.py",
      "kind": "python_function_refactor",
      "location": {"start_line": 10, "end_line": 42},
      "old_snippet": "optional old code",
      "new_snippet": "the new proposed code",
      "rationale": "short explanation of why this is better"
    }
  ]
}
```

Les modifications sont ensuite appliquées par :

- `interia_quality.refactor.ai_apply`

  - crée des backups
  - vérifie les snippets
  - applique prudemment les edits

---

## 4. Remarques

- Le pont IA est **agnostique** : il ne dépend d’aucune API propriétaire.
- Vous pouvez utiliser ChatGPT, Claude, Gemini, DeepSeek, Perplexity
ou tout autre système capable d’émettre ce JSON.
- La transparence est totale : tous les fichiers intermédiaires
(`refactor_plan.json`, `ai_request.json`, `ai_response.json`)
sont lisibles et modifiables par l’humain.
